# House Prices

Задача: предсказать цену дома. На Kaggle считают RMSE по логарифму цены.

На тест уехала линейная регрессия. Деревья, бустинги и сеть на тех же колонках были хуже: смотрел среднее и разброс по фолдам, в долларах.
На Kaggle получилось 0.13470.
Все прогоны лежат в `outputs/results.txt`.

## Запуск

Скачать `train.csv` и `test.csv` в папку `data/` со страницы соревнования:
https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

Команда из корня проекта.

Сейчас `main.py` пишет файл ответа. Линейка учится на всех очищенных домах и сохраняет `outputs/submission.csv`.

Чтобы прогнать модель по 5 фолдам и дописать журнал, внизу `main.py` раскоментируй `run_cv_txt` и закомментируй `write_submission`. Обратно так же. Одна из этих строк всегда выключена. В журнал попадают среднее и разброс в долларах. Строка дописывается в `outputs/results.txt`, та же запись лежит в `outputs/results.csv`.

Ансамбль и сеть уже лежат в своих модулях. Их подключают по одному: импорт в `main.py` и подстановка в строку `model = ...` над двумя вызовами. Так же ставится любая другая модель с `fit` и `predict`.

Seed, число фолдов и имя прогона лежат в `config.py`.

Ноутбук `house_prices.ipynb` — графики и разведка данных.
